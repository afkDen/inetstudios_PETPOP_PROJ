# Economy and progression

Model the system before implementation. Define currencies/resources, sources, sinks, progression gates, target session cadence, upgrade cost curves, rarity/expected value, failure/recovery, catch-up and anti-inflation controls.

Separate earned progression from monetization. Avoid pay-to-win pressure unless explicitly approved. Any tradable/purchasable/persistent economy is Tier 4 and requires persistence/security review plus telemetry/rollback planning.
