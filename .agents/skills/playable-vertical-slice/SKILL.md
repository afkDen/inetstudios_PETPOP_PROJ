# Playable Vertical Slice

Use playable-vertical-slice for every feature that promises player-visible mechanics. Read the issue acceptance criteria; select one start-to-finish player task. Implement real server/client/data/input/audio/feedback as scoped. Run unit/format/lint/build separately from genuine Studio playtests. Record operator, commit, personal test place, steps, console and observed results; security/multiplayer/persistence scenarios if relevant. If Studio is inaccessible, mark LIVE_TEST_PENDING and block acceptance. Independent gameplay review must reproduce or inspect real evidence.
