# Game design fundamentals

For a rough request, separate USER REQUESTED, INTERPRETED, RECOMMENDED, and DEFERRED/FUTURE.

Analyze: player fantasy; moment-to-moment/core/session/long-term loops; progression; reward cadence; faucets/sinks; difficulty; onboarding; social opportunities; replayability; content burden; Roblox fit; mobile fit; differentiation; MVP and deferred scope.

Prefer a few mutually reinforcing systems over feature accumulation.
