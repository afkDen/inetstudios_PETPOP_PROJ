# Poly Haven

Use `python scripts/polyhaven_search.py <query> --type <models|textures|hdris>` for discovery. Before downloading a production asset, inspect metadata/file variants, choose only needed resolution/formats, record source URL and CC0 license, and preserve the live-API "Powered by Poly Haven" attribution requirement when surfacing API content.

Prefer 1K/2K for prototypes and justify larger textures. Validate imported scale, pivots, materials, collision and Roblox performance.
