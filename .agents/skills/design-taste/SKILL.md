# Design Taste — Roblox adaptation

Source inspiration: `Leonxlnx/taste-skill` (MIT). This adaptation intentionally omits any instruction that would simulate/mock tool execution or evidence.

## Taste loop
1. Name the visual thesis in one sentence and list 3–5 anti-goals.
2. Generate 2–3 **controlled** alternatives that vary one meaningful axis (density, silhouette, material, hierarchy, motion), not three unrelated art styles.
3. Compare alternatives against game identity, readability, production cost, mobile fit and Roblox feasibility.
4. Select or synthesize a direction, then push it one deliberate step beyond the safest generic solution.
5. Remove decorative elements that lack hierarchy/worldbuilding purpose.
6. Favor asymmetric or distinctive composition where useful, but keep interaction affordances predictable.
7. Treat references as principles to transform, not screens to copy.
8. Judge actual pixels at target viewport and normal play distance. A self-review is not independent review.

Never invent screenshots, tool calls, user research or test outcomes.
