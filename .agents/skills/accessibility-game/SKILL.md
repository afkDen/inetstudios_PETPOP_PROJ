# Game accessibility

Accessibility requirements must be observable. Review visual, auditory, motor, cognitive, and input barriers relevant to the game. Do not rely on color alone; provide scalable readable text; support alternate inputs/remapping where feasible; expose motion/intensity controls for strong effects; avoid critical information only in audio; test focus/navigation and recovery flows.
