# Ui Production

Use ui-production when building any final player-visible UI. Begin with approved QUALITY_BRIEF screen map and annotated visual mockup for intended game art style; specify control data and server authority, mouse/touch/gamepad paths, loading/error/disabled/empty/success states. Build a reusable component family, wire real interactions and confirmations, then take actual desktop and mobile Studio screenshots. Review readability, safe zones, focus, transitions, real data, cleanup, and accessibility; block completion when a widget does nothing.
