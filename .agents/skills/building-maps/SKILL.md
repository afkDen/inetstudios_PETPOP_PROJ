# Building maps

Use `level-design` first. Build in phases: layout/blockout → traversal test → zone shells → landmarks → gameplay props → environment/art pass → optimization. Use an origin-relative spatial plan and organized folders/models. Validate spawn safety, navigation, streaming/performance, sightlines, and mobile readability before polish.

## Enforced production acceptance
Require art-bible-led landmarks, environment palette and reference mood board, approved placement metrics and composition from player camera. After blockout and traversal, a distinct art/light/set-dressing pass is required. If only blocks are built, label BLOCKOUT and block final approval.
