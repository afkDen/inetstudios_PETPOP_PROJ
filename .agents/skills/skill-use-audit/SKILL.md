# Skill Use Audit

Use skill-use-audit before implementation handoff and during independent final review. Each role gets only task-matched required skills and returns a named receipt with canonical skill path, intended decision, actual output path and validation. Check role tool permission, genuine fresh-context isolation, asset/UI production capability and Studio access before claiming the corresponding work is possible. Where native parallel agents cannot isolate context, use separate reviewed sessions/worktrees; otherwise mark the gate blocked. Never assign a role a skill that is only registered but not installed/approved.
