# Visual Production

Use visual-production when creating 3D models, props, environment, characters, lighting or textures. Before work: read approved art bible and issue QUALITY_BRIEF, secure reference/licensing or design own, record clear target examples and anti-goals. Produce silhouette/palette/material/detail family; prototype blockout and gameplay traversal first, then a separate production pass. Validate scale, texture, lighting, camera composition, asset provenance, performance and mobile read. If no free or local tool can produce approved assets, return ART_CAPABILITY_BLOCKED and request human art, do not substitute raw bricks. Required return: changes, images from actual Studio if available, asset manifest, before/after and independent visual review.
