# Building 3D objects

Assess → specify dimensions/style/pivot → plan hierarchy → build under an explicit owned Model → validate anchoring, collisions, scale, naming, performance, and visual fit. Prefer reusable modular geometry and native Parts when quality is adequate. Do not scatter unmanaged Instances across Workspace.

## Enforced production acceptance
Deliver phases separately: BLOCKOUT for spatial tests, then PRODUCTION assets with art director signoff and approved silhouette/material/lighting treatment. Label each proxy in manifest; no anonymous brick collections as final. Capture real in-game screenshots and require a separate visual reviewer.
