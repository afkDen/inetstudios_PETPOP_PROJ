# PROVIDER BENCHMARKS

No paid provider is enabled by default.

## Default asset routing

1. approved internal project asset;
2. reusable project asset family;
3. Roblox Creator Store / Toolbox;
4. Roblox Parts / procedural construction;
5. Roblox-native generation;
6. only then evaluate external providers;
7. technical cleanup where needed;
8. Studio import + game-context review;
9. provenance record;
10. approve / rework / reject.

## Candidates

### Meshy — REJECT UNDER CURRENT NO-COST POLICY
Strengths: mature API, text/image/multi-image workflows, MCP server.
Risks: paid credits; generated output still needs topology/scale/pivot/collision/style validation.

### Hyper3D Rodin — REJECT UNDER CURRENT NO-COST POLICY
Strengths: Gen-2.5 tiers, text/image workflows, common game formats, explicit mesh/material controls.
Risks: paid credits; asynchronous pipeline; must validate production suitability in Roblox.

### Tripo — DEFER / REQUIRES NEW NO-COST REVIEW
Strengths: v3 generation, multiview, conversion, decimation/mesh tools, rigging/animation endpoints.
Risks: paid credits; broad surface area can add unnecessary dependency.

Paid providers may be reconsidered only if the human explicitly changes the no-cost policy. A future provider may enter the pool only after current commercial/API terms are verified.

## Benchmark rubric when a real asset requires external generation

Score 1–5:
- silhouette accuracy;
- style adherence;
- geometry/topology;
- polygon budget;
- UV/material quality;
- artifacts/back-side completeness;
- pivot/scale;
- collision suitability;
- rig/animation suitability;
- Roblox import compatibility;
- game-context readability;
- performance;
- cost;
- turnaround;
- repeatability.

Never choose a provider from preview aesthetics alone.
