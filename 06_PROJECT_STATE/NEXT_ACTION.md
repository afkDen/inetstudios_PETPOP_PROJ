# NEXT ACTION

For a new game, follow `NEW_GAME_SETUP.md` to create a prepared checkout. Then run `python scripts/team.py setup --developer YOU --runtime <runtime>`.

After setup, capture the first human idea with `python scripts/team.py idea --file .local/ideas/game.txt --owner YOU`. The CLI creates the single Issue/task branch/changeset and a ready-to-paste AI prompt. No separate proposal or promotion PR is required in the normal v8 workflow.
